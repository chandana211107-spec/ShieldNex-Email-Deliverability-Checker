How it works

1. Format Check

Verifies whether the email follows a valid email format.

2. MX Check

Checks whether the domain has configured mail servers.

3. Result

Classifies the address as likely to be delivered, likely to bounce, or unknown based on available evidence.

Note: An MX record confirms that a domain has mail servers, but it does not prove that a specific mailbox exists. Therefore, some addresses are reported as Unknown.
